# Accent Checker (прототип)

Проверка акцента по записи голоса: FastAPI (бэкенд) + Streamlit (интерфейс).

## Установка (Windows)
1. Python 3.10 или 3.11. Создайте окружение:
   `python -m venv venv` и `venv\Scripts\activate`
2. `pip install -r requirements.txt` (torch и модели весят несколько ГБ).
3. Установите **ffmpeg** и **espeak-ng** (для британской транскрипции).
   Для espeak-ng на Windows после установки задайте путь:
   `set PHONEMIZER_ESPEAK_LIBRARY=C:\Program Files\eSpeak NG\libespeak-ng.dll`

## Запуск
**Шаг 1: заглушка** (модели не нужны):
```
set STUB=1
uvicorn backend.main:app --reload
```
Проверка: http://127.0.0.1:8000/docs, загрузите аудио в /check-accent.

**Шаги 2–3: настоящие модели** (уберите STUB):
```
uvicorn backend.main:app --reload
```
Первый запрос скачает модели (примерно 1–2 ГБ каждая) и может идти минуту.

**Шаг 4: интерфейс** (второе окно терминала):
```
streamlit run app.py
```

## Что нужно проверить самим
- Название модели акцентов: `Jzuluaga/accent-id-commonaccent_xlsr-en-english`
  (можно заменить переменной `ACCENT_MODEL`). Проверьте имя на huggingface.co.
  Модель из исходного задания `wav2vec2-base-afr-accent` я проверить не смогла.
- Модель фонем: `facebook/wav2vec2-lv-60-espeak-cv-ft` (переменная `PHONEME_MODEL`).

## Ограничения (напишите их в работе)
- Классификатор даёт вероятности по 16 акцентам, это индикатор, а не оценка.
- «British RP match» = насколько звуки близки к британскому эталону espeak en-GB.
  Это не экзаменационная оценка и не доказательство «правильного» произношения.
- Модели обучены в основном на речи взрослых; точность на голосах школьников
  не проверена.
- Записи голоса учеников: нужно согласие. Сервер удаляет файлы сразу после проверки.
- g2p_en даёт американскую транскрипцию, поэтому для британской используется espeak-ng.
